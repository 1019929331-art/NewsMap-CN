# NewsMap CN 0.3.2 候选版本

- 地图改为本地静态 SVG 背景，使用允许修改和再分发的 Natural Earth 公共领域数据；移除 DataV 省界文件及运行依赖。
- 使用中国视角数据生成底图，保留 34 个省级新闻点位、独立省份高亮、1–4 倍缩放、新闻展开、收藏和原文跳转。
- 图片与点位共用地理范围和坐标换算，窗口变化后保持对应。
- 记录固定数据版本、SHA-256、许可说明和可复现生成脚本；补充地图显示及交互回归检查。

安装版文件为 `NewsMapCN_0.3.2_x64-setup.exe`；便携版为 `NewsMapCN-portable-0.3.2.zip`，完整解压后运行，保留同目录的 WebView2Loader.dll。源码包与 SHA256SUMS.txt 同时提供。升级请运行本版安装程序，原有旧包不包含此次地图替换。

地图为概化示意图，数据许可不等于已通过地图审核；准确性核对范围和发布注意事项见 docs/MAP_ASSETS.md。截图仍由作者提供。
