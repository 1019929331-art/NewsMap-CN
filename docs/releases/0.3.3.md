# NewsMap CN 0.3.3

- 优化滚轮缩放的连续感：逐帧缓动，连续输入合并处理，反向滚动立即响应。
- 修复改变鼠标位置后继续缩放时地图突然偏移的问题。
- 统一不同滚轮输入单位，保留 1–4 倍缩放，缩回 1 倍恢复初始地图。
- 地图使用独立合成图层缩放，新闻点位与展开面板同步定位。

安装版：`NewsMapCN_0.3.3_x64-setup.exe`。便携版：`NewsMapCN-portable-0.3.3.zip`，完整解压后运行，同目录保留 WebView2Loader.dll。源码包与 SHA256SUMS.txt 同时提供。

沿用 0.3.2 的 Natural Earth 公共领域静态地图；来源及地图核对范围见 docs/MAP_ASSETS.md。
