## 功能

- 免费头条热榜及 IT之家 RSS 新闻，无需新闻 API Key。
- 按标题中的地点线索聚合新闻，支持省级点位、全国热点、原文跳转和收藏。
- 本地静态地图与省份高亮，来源为 Natural Earth 公共领域数据；支持鼠标定位的 1–4 倍平滑缩放。
- 全部新闻参与轮播，可隐藏或恢复，展开新闻列表时自动收起。
- 全国地级市天气搜索、每日一句、分钟级倒计时；倒计时日期可留空，屏保页可点击编辑。
- 空闲自动显示、托盘暂停与恢复，以及新闻和天气缓存。

## 下载与安装

- `NewsMapCN_0.1.0_x64-setup.exe`：Windows 10/11 x64 安装版，推荐普通用户使用。
- `NewsMapCN-portable-0.1.0.zip`：便携版，完整解压后运行 NewsMapCN.exe，保留同目录 WebView2Loader.dll。
- `NewsMapCN-source-0.1.0.zip`：源码归档。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

应用需要 Microsoft WebView2 Runtime。关闭设置窗口后继续在托盘运行，完全退出请使用托盘菜单。此前的 0.3.x 编号仅为本地开发版本，本次公开版本统一为 0.1.0。

## 当前限制

程序尚未进行代码签名，Windows 可能提示未知发布者。数据接口可能变更或暂不可用；地点根据标题推断，不是精确事件定位。全屏游戏和视频的兼容性取决于桌面状态，窗口视频不保证抑制弹出；本应用不替代 Windows 安全锁屏。

地图来源、概化尺度和核对范围见 docs/MAP_ASSETS.md；不声称具有官方审图批准。
