# NewsMap CN 0.3.1 候选版本

中国新闻地图屏保，适用于 Windows 10/11 x64。

## 本次整理

- 搜索全国地级市及地级行政区的天气城市；天气使用代表站点，数据可能有延迟。
- 倒计时精确到分钟，日期留空按当天计算；可在屏保页点击编辑。
- 新闻全部参与右下角轮播，可点击打开原文；展开列表时轮播卡片自动收起。
- 设置页覆盖窗口，个性化选项展开后显示。
- 修复输入文字时误触 F / D 快捷键的问题。
- 天气请求改为 HTTPS，收窄本地封面文件访问范围，更新开发依赖。
- 补充内容与界面测试、Windows CI、安装包和源码包生成脚本。

## 下载与运行

- `NewsMapCN_0.3.1_x64-setup.exe`：安装版，推荐普通用户使用。
- `NewsMapCN-portable-0.3.1.zip`：便携版，完整解压后运行 NewsMapCN.exe，不要单独移动 EXE。
- `NewsMapCN-source-0.3.1.zip`：源码候选包。
- `SHA256SUMS.txt`：校验文件。

需要 WebView2 Runtime。应用尚未进行代码签名，Windows 可能显示未知发布者提示。程序退出设置窗口后可继续在托盘运行；需要完全退出时使用托盘菜单。

## 发布状态与局限

当前为本地候选版本，截图待提供，中国省界数据的公开再分发授权仍待确认；在确认前不应公开包含该数据的源码和二进制文件。完整清单见 docs/RELEASING.md。

新闻来自免费公开热榜及 RSS，不要求新闻 API Key；接口可能限制或变更。地点按标题词语估算，不是事件定位服务。榜单获取时间不等于新闻发布时间。自动屏保和游戏、视频的兼容性仍需真实桌面场景检查，本程序不替代 Windows 安全锁屏。
