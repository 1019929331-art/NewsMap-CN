# 地图数据授权咨询

历史记录：本文件针对 0.3.1 及更早版本的 DataV 数据。0.3.2 已替换为 Natural Earth 公共领域静态地图，不再使用原省界文件；新方案见 MAP_ASSETS.md。旧包仍需要原许可，不能把当前项目的许可追溯适用于旧地图。

## 向谁咨询

[阿里云 DataV 官方说明](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/)明确写明：GeoAtlas 数据来自高德开放平台，仅供学习和交流使用，版权问题需向高德确认。

从[高德商务合作入口](https://lbs.amap.com/cooperation/cooperation/)提交以下咨询。如入口不能处理数据授权，可要求转交地图数据版权负责人，也可通过 [DataV 官方支持](https://help.aliyun.com/zh/datav/datav-7-0/support/contact-us-for-datav-7)询问对应渠道。

注册开发者账号、申请 API Key 或取得一般 API 服务许可，不应直接当作原始 GeoJSON 的公开再分发授权。是否收费、能否给个人项目免费授权，应由对方明确答复。

## 可复制的咨询文本

主题：个人免费开源项目使用及再分发 DataV.GeoAtlas 中国省界数据的授权咨询

您好，我正在开发 NewsMap CN，一款免费的 Windows 新闻地图屏保，计划在 GitHub 公开自有源码并提供 Windows 安装包与便携版。

项目目前使用 DataV.GeoAtlas 的中国省级行政区边界数据，来源为：
https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json

数据经过几何简化后保存在项目的 src/data/china.geo.json，用于在本地绘制省界及新闻地点提示，不提供导航服务。希望确认以下具体用途是否可以获得授权：

1. 将简化后的 GeoJSON 放入公开 GitHub 仓库和源码压缩包，允许他人下载及 fork。
2. 将数据嵌入免费的 Windows 安装包、便携版，供用户离线绘制地图。
3. 项目自有源码采用 MIT；地图数据单独标明来源及贵方许可，不声称 MIT 覆盖地图数据。第三方 fork 或再分发需要遵守哪些额外条件？
4. 是否有适用于个人免费开源项目的免费授权？如需付费，请说明授权范围、期限和费用。
5. 应保留哪些署名、版权标识或审图信息？几何简化以及截图展示是否需要额外确认？

如上述用途不能授权，请明确哪些可以、哪些不能，以及是否有适合本项目的替代数据或服务方案。希望通过官方邮件、工单或正式协议取得可留存的书面答复。

谢谢！

## 收到答复后

- 核对答复是否同时覆盖公开数据文件、离线安装包和第三方 fork；只允许展示不等于允许分发文件。
- 保存原始邮件或工单；公开仓库只放可公开的授权摘要及必要署名，移除个人联系方式和合同敏感信息。
- 更新 THIRD_PARTY_NOTICES.md 和发布清单。若无法获得适用许可，先替换为许可明确且适合本项目的数据，再发布包含地图的源码及安装包。

以上是项目的授权核对流程，不代表数据提供方已经许可。
